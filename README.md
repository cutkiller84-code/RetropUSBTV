# RetropUSBTV
RetropUSBTV Android app

RetroPUSBTV

Android TV-app för retrospel med en meny inspirerad av Batocera och EmulationStation.

Funktioner vi vill bygga

- Bluetooth-handkontroller.
- Navigering med TV:ns fjärrkontroll.
- Läsa spel från USB-hårddisk och minneskort.
- Starta spel med kompatibla Android-emulatorer.
- Egen spelbibliotekshantering.

Status

Under utveckling. Målet är en installerbar APK för Android TV.

Spel och BIOS-filer tillhandahålls av användaren. Appen ska inte innehålla olagligt distribuerade spel.
